# Agent guidance — php-io-extensions/appkit

1. **Read [`.okf/index.md`](.okf/index.md) first** before changing the API, the Objective-C, or packaging. Open only the concepts the change touches.
2. **AppKit, 1:1.** One PHP method = one native call (AppKit, Foundation, Core Foundation, Core Graphics, QuartzCore, AVKit/AVFoundation/CoreMedia, IOKit, GameController, OpenGL), under its native name and signature: class = native class, selector parts joined (`nextEventMatchingMask:untilDate:inMode:dequeue:` → `nextEventMatchingMaskUntilDateInModeDequeue()`), CF/CG function on a type = method with the type prefix dropped. No defaults, no composites, no conveniences. The toolkit's behaviour passes through: nil, NO, clamped values, error codes and AppKit's own exceptions reach PHP as AppKit produces them. See [`.okf/api/surface.md`](.okf/api/surface.md).
3. **Refusals.** The rule, verbatim:
   > A refusal is the extension declining to make the native call. The extension may refuse only when making it would cause (1) memory unsafety — the call would dereference a native object the PHP wrapper no longer validly references; (2) uncatchable process death — SIGSEGV, SIGBUS, abort(), or an ObjC/C++ exception unwinding through Zend frames; (3) VM corruption — PHP code run on a non-PHP thread or illegal engine re-entry. Nothing else justifies a refusal: return codes, nil, clamping, logs, odd but documented results pass through. Every refusal needs a probe on a real build for that exact call. Translation (an NSException AppKit raised, after the native call, turned into AppKitException) is not a refusal. A need of code built on the extension is solved in that code, not here.

   Kept refusals and translation: [`.okf/architecture/errors-and-threads.md`](.okf/architecture/errors-and-threads.md).
4. **Glue** is the only native code beyond the calls: native subclasses and callbacks PHP cannot write itself, plus value marshalling and the pointer hand-off. Each forwards the native arguments it receives and returns PHP's result to the native caller, and adds nothing else: no flag combining, no context dropping, no make-current or flush, no result coercion. The glue classes, as `bindings.json` `glue` names them: `AppKitException`, `ObjCDelegate`, `ObjCTarget`, `ObjCObserver`, `ObjCDrawView`, `ObjCOpenGLView`, `ObjCStageWindow`, `NSEvent::addLocalMonitorForEventsMatchingMaskHandler`, `NSNotificationCenter::addObserverForNameObjectQueueUsingBlock`, `CFFileDescriptor::create`, `GCController::startWirelessControllerDiscoveryWithCompletionHandler`, `CGDataProvider::createDirect`, `NSObject::pointer` / `fromPointer`, `CFType::pointer`. See [`.okf/architecture/glue.md`](.okf/architecture/glue.md).
5. **Out-parameters.** A C scalar out-parameter is a by-reference PHP parameter in native position (`CGDisplay::getActiveDisplayList(int $maxDisplays, ?array &$activeDisplays, ?int &$displayCount)`). An ObjC struct out-parameter comes back in a returned array (`glyphRangeForCharacterRangeActualCharacterRange()` = `[glyphRange, actualCharacterRange]`). Native error codes (CGError, IOReturn) are returned as `int`, compared with `kCGErrorSuccess` / `kIOReturnSuccess`. nil comes back as `null`.
6. **The guard.** ext-guard checks every edit to this repo in Claude Code, Cursor and the git hooks. If it blocks an edit, fix the edit; never route around it. `bindings.json` sections: `symbols` — an agent may add entries, validated against the SDK headers; `glue`, `helpers`, `sites` and `typemap` — only the maintainer (Angel) edits them.
7. **A kept refusal** carries `/* binding:<id> */` on its throw line, has its `sites` entry in `bindings.json`, and a probe test in `tests/Probes` that shows the crash with the check off. Probe builds use `./configure --enable-appkit-probes`; in that build `APPKIT_PROBE_OFF=<id>` turns one site's check off. Never ship a probe build.
8. **Objective-C on the Zend API**, `-fno-objc-arc -fobjc-exceptions`: retain/release by hand. Every binding body runs inside `APPKIT_BEGIN … APPKIT_END`. One `src/<Group>.m` per stub; `config.m4` lists the sources and frameworks.
9. **The stub is the declaration.** Edit `stubs/*.stub.php`, regenerate with `php84 /opt/homebrew/opt/php@8.4/lib/php/build/gen_stub.php stubs`, commit both. Never hand-edit `*_arginfo.h`. Enum values come from the SDK and are `_Static_assert`-checked; constants via `@cvalue`.
10. **Build.** `bash install-macos.sh` into Homebrew `php@8.4` (`php84`) and `php@8.4-zts` (`zhp`). Pest v4 at `-d memory_limit=128M`, `XDEBUG_MODE=off` for any timing, in a logged-in GUI session. Run the test files a change touches; gate a commit on the run's exit code. Probe steps: [`.okf/runbooks/build.md`](.okf/runbooks/build.md).
11. **Durable facts go in `.okf`.** Update the matching concept, bump its `generated.at`, append `.okf/log.md`. The bundle documents the package, never a session.
12. **Version** is `PHP_APPKIT_VERSION` in `php_appkit.h`: 0.10.2. It moves only past a published tag; tags drive Packagist. `os-families`: darwin.
