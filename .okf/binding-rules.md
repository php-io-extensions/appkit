# AppKit binding rules

The extension exposes the AppKit headers at
`/Library/Developer/CommandLineTools/SDKs/MacOSX.sdk/System/Library/Frameworks/AppKit.framework/Headers/`
into PHP 1:1. Layering: **ext = AppKit + unavoidable glue; jovian/appkit = PHP
function per ext call; venusian-appkit = composition; surface = abstraction.**

## The one rule

**One ext call = one Objective-C message send.** Composition belongs in
PHP-land, never below. The single sanctioned composite is `alloc`+`init...`
inside init bindings — object construction is glue, not composition (decision:
Angel, 2026-08-27). `check-parity.php` enforces this mechanically.

A concrete class whose own header declares no initializer cannot be
allocated through the ancestor binding (`NSControl::initWithFrame` always
allocs an `NSControl`). Those classes synthesize the nearest bound ancestor's
designated initializers as `/*@zep-construct ... */` construction glue,
identical grammar to `@zep`, allocing the concrete class. The generator
emits them like any other binding; the header audit excludes them from
`bound` (printed as `construct=N`) so `bound + reserved` still equals the
SDK member count. Access-only classes — `NSApplication`, `NSEvent`,
`NSScreen`, `NSNotificationCenter` — are exempt and live on the audit
whitelist. A non-exempt class with no `init*`, no class-method factory
(no-handle `@zep` returning `int`), and no `@zep-construct` fails the audit.

| AppKit | PHP |
|---|---|
| `@interface NSButton` | `AppKit\NS\NSButton\NSButton` static class, file `appkit/ns/nsbutton/nsbutton.zep` |
| `- (void)setBezelStyle:(NSBezelStyle)s` | `NSButton::setBezelStyle(int handle, int style): void` |
| `@property NSBezelStyle bezelStyle` | `bezelStyle(int handle): int` + `setBezelStyle(...)`; `getter=isX` → `isX()` |
| `- (id)initWithTitle:action:keyEquivalent:` | `initWithTitleActionKeyEquivalent(string, string, string): int` (`alloc`+init, returns handle) |
| `+ (X)classMethod` | static, no handle param |
| BOOL / NSInteger / CGFloat / NSString / enum | bool / int / double / string (nullable → `var`, null = nil) / int |
| any object, `id`, `SEL` | int handle (0 = nil) / string selector |
| opaque C pointers (`NSModalSession`, …) | int (pointer bits, **not** a registry handle; 0 = NULL) |
| NSRect / NSPoint / NSSize / NSRange / NSEdgeInsets | doubles in, assoc array out |
| scalar out-params (`float *`, `NSInteger *`, …) | assoc array out, keys = ObjC parameter names (e.g. `getPeriodicDelay:interval:` → `{delay, interval}`) |
| `NSArray<NS*>` / `NSArray<NSString*>` | array of handles / strings |
| `NSArray<NSArray<NS*>*>` | array of arrays of handles (`ns_arg_object_array_array`) |
| blocks, `NSError**`, `NSCoder`, `Class`, `NSAttributedString`, `NSData`, deprecated | not bound; kept as commented `@reserved` signature (nothing silently omitted) |
| inherited methods | bound once on the declaring class; handles are untyped so `NSView::setFrame($button, …)` works |
| inherited designated initializer on a class with none of its own | `@zep-construct` on the concrete class (`NSSwitch::initWithFrame` → `[[NSSwitch alloc] initWithFrame:]`); access-only classes exempt |

## Mechanics

- C symbol: `ns_<classlower>_<selector_snake>(zval *…)`; int/bool/double return
  by value, string/array/var written into a leading `zval *return_value`.
- Every C prototype carries a `/*@zep NS\NSButton setBezelStyle(int handle, int style) -> void */`
  line, or `/*@zep-construct … */` for synthesized inherited designated
  initializers. `.zep` files and optimizers are **generated** from those
  lines by [`scripts/gen-zep.php`](/toolchain.md) — never hand-written.
- Zephir reserved words in selectors **and parameter names** get a trailing
  underscore (`print_`, `callable_`, `object_`).
- All-caps selectors and parameter names are emitted mixed-case (`URL` → `Url`,
  affecting `NSPathCell` / `NSPathComponentCell` / `NSPathControl` /
  `NSPathControlItem` / `NSSavePanel`). Zephir lexes an all-caps identifier as a
  constant token, so it cannot sit in a method or parameter position, and a
  trailing underscore does not help (`URL_` is still all-caps). PHP resolves
  method names case-insensitively, so callers may still write `URL()`.
- Marshalling only via `src/ns-value.h`. All glue only in
  [`AppKit\Bridge\Bridge`](/bridge.md); no other `NSPhp*` class may exist.
- Constants live in `jovian/appkit` as PHP enums, never in the ext.
